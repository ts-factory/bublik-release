# Chat

Chat answers questions about your test data in plain language, such as "what failed in last night's runs?" or "has this test failed like this before?" It can look through runs, results, logs, history, dashboards and reports for you.

Open it with **Chat** in the sidebar. Chat is off by default, so the row appears only once an admin has turned it on. If it says no chat models are configured, ask your admin to add one.

To set it up, see [AI Chat](../03-configuration/06-chat/index.md).
